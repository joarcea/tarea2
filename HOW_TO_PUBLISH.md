# Publicación en Hosting Gratuito

A continuación, dos opciones simples para publicar el sitio **sin backend**:

## Opción 1: GitHub Pages
1. Cree un repositorio en GitHub llamado `tarea2-css3-utn`.
2. Suba el contenido de la carpeta `proyecto_css3_tarea2_utn/` (incluyendo `index.html` y `css/`).
3. En **Settings → Pages**, elija **Branch: main** y carpeta **/root**. Guarde.
4. Espere 1–2 minutos. La URL pública será: `https://<su_usuario>.github.io/tarea2-css3-utn/`.

## Opción 2: Netlify (arrastrar y soltar)
1. Cree una cuenta en https://app.netlify.com/.
2. Haga clic en **Add new site → Deploy manually**.
3. Arrastre la carpeta `proyecto_css3_tarea2_utn/` al panel.
4. Obtendrá una URL pública del tipo `https://<nombre>.netlify.app/`.

> Recuerde colocar la URL pública en los comentarios de la asignación en el campus.
